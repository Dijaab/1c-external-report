Отчет СКД: Анализ продаж и остатков

Назначение отчета
Внешний отчет (.erf) для конфигураций на платформе 1С (ERP / Управление торговлей), предназначенный для сверки и сопоставления показателей продаж и актуальных остатков товаров на складах. Отчет объединяет данные из регистров накопления и позволяет анализировать объемы продаж, выручку, себестоимость в разрезе клиентов и номенклатуры, рентабельность продаж, а также текущие остатки товаров на складах.

2. Технические характеристики

Инструмент разработки: Система Компоновки Данных (СКД).

Основные источники данных: РегистрНакопления.ВыручкаИСебестоимостьПродаж.Обороты и регистр накопления остатков номенклатуры.

Параметры: Начало периода и Конец периода (тип данных: Дата), вынесенные в пользовательские настройки с быстрым доступом на форме отчета.

3. Порядок использования

Запустить конфигурацию 1С в режиме Предприятие.

Открыть внешний отчет через меню Файл - Открыть.

В шапке отчета установить требуемый интервал дат (Начало периода и Конец периода).

Нажать кнопку Сформировать.

4. Требования к среде

Платформа: 1С:Предприятие 8.5.

Конфигурация: 1С:ERP Управление предприятием / 1С:Управление торговлей.
